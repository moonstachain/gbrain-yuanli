# 原力叙事 2.0｜Yuanli Narrative 2.0 Canon

Status: `CANDIDATE / YNS2-SK-A`
Version: `2.0.0`

## 0. 核心定义

原力叙事 2.0 不是“把内容写得更刺激”，而是把事实、人物、选择、机制、时代与后果编译成一条人脑愿意走完、又经得起事实核验的认知路径。

> 人物只是入口，命运才是结构，时代才是背景，选择才是内容，规律才是资产。

目标函数：

`想点开 × 看下去 × 记得住 × 愿意转述 × 相信你`

## 1. 五台发动机

1. **悬念发动机**：我为什么必须继续看？
2. **人物发动机**：这个人为什么会这样选择？
3. **因果发动机**：究竟是什么导致了什么？
4. **时代发动机**：为什么偏偏发生在那个时代？
5. **认知发动机**：看完以后，我怎么看世界？

好的叙事必须同时产生：悬念、人物可理解性、因果解释、时代定位与认知回扣。

## 2. Block 0｜Narrative Constitution

任何正式写作开始前，先冻结六项：

| 字段 | 必答问题 |
|---|---|
| Fate Paradox | 最反常识的结局是什么？ |
| Mother Question | 整篇只回答哪个问题？ |
| Character Thesis | 这个人反复出现的选择模式是什么？ |
| Era Thesis | 哪个时代力量放大了他？ |
| Competing Explanation | 还有哪些竞争解释？ |
| Truth Boundary | 哪些是事实，哪些只是推断？ |

并写出一句：

> **This is not a story about X. It is a story about Y.**

如果这句话立不起来，不应进入正文。

## 3. YFN12｜12-Block 命运结构

### ACT I — HOOK

**B01｜Fate Paradox｜命运反差**  
从今天的结局倒着开场，制造必须被回答的问题。

**B02｜Mystery Contract｜核心谜题**  
与读者签订认知合同：看到最后，究竟会知道什么？

**B03｜Origin Constraint｜源头约束**  
只保留与后来命运有关的早年经历，不写履历百科。

**B04｜Genesis Case｜第一次显影**  
找到人物第一次做出“后来还会重复的选择”。

### ACT II — BUILD

**B05｜Character OS｜人物操作系统**  
把人物从形容词改写为行为算法：输入 → 判断 → 动作 → 反馈。

**B06｜Winning Machine｜胜利发动机**  
回答他到底靠什么赢：能力、模式、产品、组织、资本或形式。

**B07｜Era Amplifier｜时代放大器**  
把个人嵌入行业与时代，区分 Person Alpha 与 Era Beta。

**B08｜Hidden Crack｜繁荣裂缝**  
找到成功机制何时开始制造自己的脆弱性。

### ACT III — FATE

**B09｜Counterintuitive Turn｜反常识转身**  
所有人做 A 时，他为什么做 B？

**B10｜Foil Fork｜命运分叉**  
用同代人、同赛道或相似约束形成自然对照组。

**B11｜Reality Settlement｜现实结算**  
让时间、现金流、作品、组织、生存状态或历史结果替作者裁判。

**B12｜Universal Law｜第一性回扣**  
回答开头问题，并把人物故事升级为可迁移的世界模型，最后回到读者。

结构压缩：

`4 Blocks 拉你进去 → 4 Blocks 让人物成立 → 4 Blocks 完成命运结算`

## 4. 7-Beat｜每个 Block 的微循环

每一个关键段落默认使用：

`Scene → Tension → Choice → Mechanism → Consequence → Compression → Bridge`

- **Scene｜场景**：发生在哪里？
- **Tension｜张力**：哪里不对劲？
- **Choice｜选择**：他做了什么？
- **Mechanism｜机制**：为什么有效/无效？
- **Consequence｜结果**：随后发生了什么？
- **Compression｜金句**：这一幕究竟意味着什么？
- **Bridge｜过桥**：新的问题又出现了什么？

宏观靠 YFN12，微观靠 7-Beat。

## 5. 双时间轴

原力叙事同时运行两根时间轴：

**外层｜时代状态**  
`形成 → 繁荣 → 过热/冲突 → 断裂/重构`

**内层｜人物 OS**  
`第一次选择 → 第一次显影 → 反复验证 → 极端检验`

两条线在 B09 汇合，形成 **Fate Moment｜命运时刻**。

## 6. Truth Gate

所有承担主因果的 Claim 必须标注认识论状态：

- `[F] Fact`：可直接陈述。
- `[R] Reported`：明确来自某人回忆、采访或二手报道。
- `[I] Inference`：作者/Agent 的解释性推断。
- `[H] Hypothesis`：竞争性假说，必须允许输。
- `[U] Unverified`：未经核验，不得承担主因果。

核心纪律：

> **越精彩的细节，越要查证。**

详见 `TRUTH-GATE.md`。

## 7. 三种核心人物结构

原力叙事不强迫所有人物拥有同一种“一核”。至少允许：

1. **Problem Arc｜问题型**：一生反复追问同一道问题。典型 Golden Case：Christopher Nolan。
2. **Unbetrayable Stance｜立场型**：现实越复杂，越显出什么不能背叛。典型 Golden Case：Hayao Miyazaki。
3. **Boundary / Capability / Time / Feedback / Recursion 等其他镜型**：只有证据支持时才建立，不允许套模板。

## 8. 三类常用对象

### 人物志
不是替一个人总结一生，而是看一个问题、选择模式或不可背叛立场怎样穿过几十年。

### 商业案例
不是复述公司做过什么，而是解释模式如何建立、被时代放大、暴露裂缝、穿越或失败，并被现实结算。

### 自我叙事
不是回忆过去，而是识别自己反复在回答什么问题、守住什么立场、在哪些命运分叉中作出选择。

## 9. 质量 Benchmark

每篇 1–5 分，至少检查：

- **Hook**：30–60 秒内形成真正想知道答案的问题。
- **Character**：读完能预测“如果遇到 X，他通常会怎样选择”。
- **Causality**：不是时间先后，而是机制清楚。
- **Tension**：至少存在真实状态转折，不靠夸张制造。
- **Insight**：读完获得人物之外的世界模型。
- **Trust**：事实、转述、推断、假说、未核验清楚分层。

### Veto Gate

以下任一出现即不合格：

1. 没有唯一 Mother Question。
2. 全文只是时间流水账。
3. 关键因果建立在未经核验传闻上。
4. 结尾没有回答开头的问题。

## 10. AI-Native 编译顺序

Agent 不得直接从素材跳到全文。默认顺序：

1. Source Grounding
2. Narrative Constitution
3. YFN12 Skeleton
4. 7-Beat Expansion
5. Truth Gate
6. Render to requested medium
7. Benchmark / Self-review

输出媒介可以变化：长文、视频脚本、播客提纲、课程讲义、商业案例、人物志、信息爆炸图。

同一个 Kernel，不同 Projection。

## 11. 最终皇冠

> **原力叙事 2.0，不是把浅内容讲得更刺激；而是把深认知，包装进一条人脑愿意走完的路。**
